# Logwell documentation

Logwell is a task manager for Obsidian, with a calendar, an Eisenhower matrix, a focus timer and habits. If you are starting out, begin at the top.

## Start

- [Getting started](getting-started.md): install Logwell, create a database and add your first task.

## Everyday basics

- [Tasks](tasks.md): add, edit, complete and delete tasks, with dates, priorities, subtasks, notes and undo.
- [Quick Add](quick-add.md): type a task as one line and let Logwell find the date, list, tags and more.
- [Lists, sections and tags](lists-and-tags.md): sort tasks into lists and sections, and label them with nested tags.
- [Board](board.md): see a view as columns of cards and drag tasks between them.
- [Views](views.md): Today, Upcoming, Inbox, Completed and Trash, with sorting, grouping and search.

## Features in depth

- [Repeating tasks](repeating-tasks.md): repeat a task, complete or skip an occurrence and end a repeat.
- [Calendar](calendar.md): the week and month views, and dragging tasks to another day or time.
- [Eisenhower matrix](matrix.md): sort tasks by urgency and importance, and move them between quadrants.
- [Focus](focus.md): work in timed rounds with breaks, on a task or on none.
- [Focus record](focus-record.md): see your saved rounds, fix them and recover a timer after a crash or sleep.
- [Habits](habits.md): create habits, check in, and follow goals and streaks.
- [Habit reminders](habit-reminders.md): get a daily nudge for a habit that is not done.
- [Task block in notes](dashboard-block.md): show a live list of tasks inside any note.
- [TickTick sync](ticktick-sync.md): keep chosen lists in step with TickTick, both ways.
